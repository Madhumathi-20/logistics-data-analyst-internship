# Logistics Data Analyst Internship Project

## Project
Strategic Planning, Data Cleaning, Advanced Analysis, Predictive Modeling and Optimization in Logistics.

## Dataset
This project uses a simulated logistics dataset designed around the structure and business themes of the publicly available DataCo Smart Supply Chain dataset. The reference dataset contains supply-chain transaction, shipping, product, customer and delivery fields.

Reference: DataCo Smart Supply Chain for Big Data Analysis (Kaggle).

## Important note
The dataset is simulated for internship demonstration and reproducibility. It should be described as a simulated logistics dataset based on a public logistics dataset structure, not as proprietary company data.
